# Mixed arithmetic, memory, dependency, and resource-pressure test.
# Change only Issue width to compare widths 1, 2, 3, and 4.
# All nine supported opcodes execute; the loop gives 73 dynamic instructions.
# Small reservation stations/LSQ and a 28-entry ROB exercise issue stalls.
# One-cycle memory lets independent arithmetic and stores overlap effectively.

               # of rs         Cycles in EX    Cycles in Mem   # of FUs
Integer adder   2               1                               1
FP adder        2               3                               1
FP multiplier   2               15                              1
Load/store unit 3               1               1               1

ROB entries = 28
Issue width = 4
R4=10, R5=3, R15=2
F1=2.0, F2=3.0, F3=4.0, F4=5.0, F5=6.0, F6=7.0, F7=8.0
Mem[0]=10.0, Mem[4]=20.0, Mem[8]=30.0, Mem[12]=40.0

# A long multiply delays retirement while independent work uses other FUs.
# Interleaved integer/FP operations and stores expose useful issue parallelism.
# Stores wait for their FP source values and exercise the shared memory port.
Mult.d F8 F1 F2
Addi R10 R4 1
Add.d F9 F1 F2
Sd F9 64(R0)
Sub R11 R4 R5
Sub.d F10 F4 F3
Sd F10 68(R0)
Add R12 R4 R5
Add.d F11 F5 F6
Sd F11 72(R0)
Addi R13 R4 2
Sub.d F12 F7 F1
Sd F12 76(R0)
Add R14 R4 R5
Add.d F13 F2 F3
Sd F13 80(R0)
Sub R16 R4 R5
Add.d F14 F4 F5
Sd F14 84(R0)
Addi R17 R4 3
Sub.d F15 F6 F2
Sd F15 88(R0)
Add R18 R4 R5
Add.d F16 F1 F7
Sd F16 92(R0)
Sub R19 R4 R5

# Four loads compete for three LSQ entries and one memory port.
# Three FP consumers then compete for two adder reservation stations.
Ld F24 0(R0)
Ld F25 4(R0)
Ld F26 8(R0)
Ld F27 12(R0)
Add.d F17 F24 F25
Sub.d F18 F24 F26
Add.d F19 F24 F27

# These multiplies wait for F17 and pressure the two multiplier RS entries.
Mult.d F20 F17 F2
Mult.d F21 F17 F3
Mult.d F22 F17 F4

# A producer and three consumers pressure the two integer RS entries.
Addi R20 R4 1
Add R21 R20 R5
Sub R22 R20 R5
Addi R23 R20 2

# Store data depends on a multiply. The matching load exercises forwarding.
# F23 must receive 90.0, not the initially zero value at memory address 128.
Sd F20 128(R0)
Ld F23 128(R0)
Sd F18 132(R0)
Sd F19 136(R0)

# Copy the eight FP results into two output arrays at byte addresses 160/192.
# Each integer address producer also tests waiting for an LSQ base operand.
# R4/R5 are reused only after all earlier arithmetic has captured their values.
Addi R1 R0 160
Sd F9 0(R1)
Sd F9 32(R1)
Addi R2 R0 164
Sd F10 0(R2)
Sd F10 32(R2)
Addi R3 R0 168
Sd F11 0(R3)
Sd F11 32(R3)
Addi R4 R0 172
Sd F12 0(R4)
Sd F12 32(R4)
Addi R5 R0 176
Sd F13 0(R5)
Sd F13 32(R5)
Addi R6 R0 180
Sd F14 0(R6)
Sd F14 32(R6)
Addi R7 R0 184
Sd F15 0(R7)
Sd F15 32(R7)
Addi R8 R0 188
Sd F16 0(R8)
Sd F16 32(R8)

# This simulator uses byte branch displacements: -8 targets the preceding Addi.
# R15: 2 -> 1 -> 0, so Bne is taken once and then falls through.
Addi R15 R15 -1
Bne R15 R0 -8
Addi R30 R0 123
